# Расширение для TradingView

Добавляет в контекстное меню инструмента «Длинная/Короткая позиция» пункт
**«Открыть сделку в журнале»**. По клику открывается форма новой сделки
журнала с тикером, направлением, входом и стопом этой позиции. Сделку
открываешь сам кнопкой — ссылка только заполняет поля.

Работает в десктопном Chrome/Brave/Edge на tradingview.com. В приложениях
TradingView (iPhone, десктоп) расширений нет.

## Установка

1. `brave://extensions` (в Chrome — `chrome://extensions`).
2. Справа вверху включить **Режим разработчика**.
3. **Загрузить распакованное** → выбрать папку `extension/tradingview`.
4. Открыть (или перезагрузить) график на tradingview.com.

После правок в файлах — кнопка ↻ у расширения на той же странице и
перезагрузка графика.

## Как пользоваться

Правый клик по нарисованной позиции → **Открыть сделку в журнале**. Журнал
откроется в новой вкладке; если не залогинен — сначала вход, потом форма.

## Как устроено

- `content.js` работает в мире страницы (`"world": "MAIN"`), читает
  выделенную фигуру через внутренний `window.TradingViewApi` и вставляет
  пункт — копию существующей строки меню с другим текстом.
- `levels.js` — расчёты без DOM: вход отдаётся ценой, стоп — в тиках; размер
  тика собирается из форматтера цен графика и сумм, которые считает сам
  инструмент. Тесты: `npm test` (`levels.test.cjs`).
- Разрешений расширению не нужно: ни доступа к вкладкам, ни сети. Данные
  никуда не отправляются — только открывается ссылка на журнал.

`window.TradingViewApi` не документирован. Если TradingView его поменяет,
пункт перестанет появляться (в консоли будет `[trading-journal]`), а сам
график продолжит работать.

Адрес журнала — константа `JOURNAL_URL` в начале `content.js`.
